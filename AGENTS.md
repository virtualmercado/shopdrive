- Plan codes: free|pro|premium|marca; MARCA = Premium + brand capabilities in `PLAN_LIMITS` (planLimits.ts) and `get_effective_store_plan`; sale gated by flag ENABLE_PLAN_MARCA via `is_plan_marca_enabled()` (fail-safe false). Why: prevents MARCA from ever resolving to Free.
- Plan contracts: versions in plan_contract_versions (immutable once published, SHA-256 by trigger), current pointer in plan_contract_settings, immutable plan_contract_acceptances written only by service-role RPC record_plan_contract_acceptance via edge function accept-plan-contract. Why: legal evidence must never be rewritten; acceptance never activates a plan.
- Lojas próprias MARCA vivem só em `brand_account_owned_stores` (slot 1=primary=owner, slot 2=secondary); herança via `get_brand_inherited_plan` dentro de `get_effective_store_plan` (planSource/ownedStoreRole) e `resolveStoreEntitlements` no front. Why: uma única assinatura financia 2 lojas sem dar autoridade de rede à secondary; `source_template_id` nunca conta como propriedade.
- Minha Rede (MARCA): toda métrica de rede sai de `compute_brand_network_metrics` (cliques = template_click_events.counted, ativações = profiles.source_template_id válidos, operacional = `_bn_store_facts`, espelho set-based de compute_store_completion_snapshot); cliente só via `get_my_brand_network_*` (owner+primary+MARCA direto+flag), admin via `admin_get_brand_network_*`. Why: fórmula única, sem SELECT direto em profiles e sem secondary atravessar.
